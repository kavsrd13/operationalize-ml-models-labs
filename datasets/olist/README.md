# Bundled Olist data

`Ecommerce Dataset.zip` contains the nine original Olist CSV files. Run
`python 00-Shared-Setup-and-Data/scripts/bootstrap.py` from the streamlined
collection root to extract them locally
to `datasets/olist/Ecommerce Dataset/`; the extracted files are ignored by Git.
Keep only one source-data copy in the repository. See `../../DATA_ATTRIBUTION.md`
for credit and the CC BY-NC-SA 4.0 noncommercial/share-alike terms.
